Zeus Pro V3.4 指挥官实战终端 (V800) 🚀
本版本为 4D-E-T 5.0 宙斯盾 架构下的深度实战型号，代号 V800。其核心定位是**“去伪存真”**：通过引入严苛的实战滑点、容量限制以及分段统计逻辑，彻底剥离回测中的理想化幻觉，为指挥官提供一份“带血”的真实回测数据与实盘操作指令。
1. 核心进化：V800 vs 早期版本 🧬
相比于 V604 等版本，V800 进行了以下关键实战升级:
 * 跳空损耗模拟：修正了止损逻辑。若股价开盘即跌破止损位，系统将强制以开盘价成交，而非理想的止损价。
 * 成交容量限制：引入 capacity_limit（2%）。单笔成交量不得超过当日该股总成交额的 2%，防止小盘股回测中出现“无法成交”的虚假获利。
 * 双周期独立统计：代码自动将数据切分为 2024-2025（纯回测期） 与 2026 至今（实盘模拟期），通过 calculate_metrics 函数独立输出两段绩效，真实评估策略在当下的适应性。
2. 策略核心配置 (Config) ⚙️
| 参数 | 设定值 | 逻辑说明 |
|---|---|---|
| 初始/实盘本金 | 150,000.0 | 基于 A 股主板操作门槛设定的基准本金 |
| 风险基准 (1R) | 4% | 单笔交易最大允许损失总资产的 4% |
| 滑点 & 规费 | 0.12% / 0.08% | 涵盖冲击成本、印花税及券商佣金 |
| 止损系数 | 2.0 ATR | 采用动态追踪止损，以最高价回落 2.0 倍 ATR 为撤退红线 |
3. 因子引擎与风控逻辑 🛡️
3.1 职业因子引擎 (Sectional Rank)
策略不再盲目看绝对涨幅，而是采用每日截面排序：
 * 动量评分 (f_mom)：取全市场个股 10 日涨幅的百分比排名。
 * 活跃度评分 (f_active)：计算成交额的 20 日 Z-Score，只打猎有资金深度介入的标的。
 * Bias 偏离度限制：若股价高于 MA20 均线 15%，评分强制清零，防范情绪末端的“最后一棒”。
3.2 进场条件
 * 牛熊生命线：个股必须站稳 200 日均线 (MA200) 以上。
 * 涨停过滤：若个股集合竞价直接封死涨停，判定为买不入，系统自动取消信号。
4. 指挥官终端报表输出 📊
运行 python v800.py 后，终端将实时生成三部分核心内容：
 * 核心绩效指标表：包含回测/实盘的收益率、最大回撤、夏普比率、胜率、盈亏比以及凯利仓位建议。
 * 实盘持仓监控：实时扫描当前持仓的“安全垫”深度（距离止损价的百分比）。若跌破或接近止损，会触发 !! 立即卖出 !! 警报。
 * 明日开仓指令：自动根据当前实盘剩余本金，计算明日建议买入的精确股数、建议触发价及初始止损位。
